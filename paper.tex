\section{Definitions of our terms}

\begin{definition}
    The category of simple graphs $\G$ has as its objects simple graphs, which we consider to be a finite set $V$ equipped with a reflexive and symmetric binary relation $E$ -- that is, our simple graphs are finite, have no double edges, and have loops at every vertex\footnote{The final property here may seem a bit unusual, but it simplifies our proofs in some places, without really affecting much. }. A morphism from $H = (V, E)$ to $G = (V', E')$ is an injective set function $f: V \to V'$ such that whenever $uEv$, we also have $f(u)E'f(v)$. That is, a morphism from $H$ to $G$ is a way of realizing $H$ as a subgraph of $G$.
\end{definition}

\begin{definition}
    The category of partitioned sets $\Pset$ has as its objects sets $V$ with an equivalence relation $\sim$. A morphism in $\Pset$ from $(V, \sim)$ to $(W, \approx)$ is a set function $f: V \to W$ such that whenever $v\sim w$, $f(v) \approx f(w)$. So in the case where $V = W$, $f = \Id$ is a morphism if $\approx$ is a coarsening of $\sim$.
\end{definition}

\begin{definition}
    A clustering scheme is a function\footnote{Technically, of course, neither $\G$ nor $\Pset$ are small categories, so the word ``function'' should be read as ``class function'' here, not in the usual sense of the word. We sweep this issue under the rug here, because it will never affect anything.} $\Clust$ that sends simple graphs to partitioned sets, with the same underlying set. We say that it is \emph{functorial} if it is a functor from $\G$ to $\Pset$.
\end{definition}

\begin{definition}
    A clustering scheme $\Clust$ is \emph{excisive} if, for all graphs $G = (V, E)$, it holds for every equivalence class $A$ of $\Clust(G)$ that $\Clust(G|_A) = (A, A^2)$. That is, if we take a graph, cluster it, pick out one of the parts, and cluster that part alone, that part will be clustered into a single part.
\end{definition}

\section{Representability}

\begin{definition}
    Given a not necessarily finite set $\Omega$ of simple graphs, we define the endofunctor $F_\Omega$ on $\G$ as follows: For any graph $G = (V, E)$, $F_\Omega(G)$ is a graph on the same vertex set, and there is an edge between $u$ and $v$ in $F_\Omega(G)$ whenever there exists some subgraph of $G$ containing both $u$ and $v$ which is isomorphic to some $\omega \in \Omega$.

    Equivalently, there is an edge $uv$ in $F_\Omega(G)$ whenever there exists an $\omega \in \Omega$ and a morphism $f: \omega \to G$ such that $f(\omega) \ni u, v$.

    On morphisms, $F_\Omega$ is always just the identity.
\end{definition}

\begin{lemma}\label{lemma_representable_endofunctor_is_functor}
    For any representing set $\Omega$ of simple graphs, $F_\Omega$ is indeed an endofunctor on $\G$.

    \begin{proof}
        That it always gives a simple graph and that it respects identity morphisms and composition of morphisms is easy to see. The only thing we actually need to check is that if $f: H \to G$ is a morphism, then $F_\Omega(f) = f: F_\Omega(H) \to F_\Omega(G)$ is also a morphism.

        Unwrapping this statement, what we need is that, for any morphism $f: H \to G$, whenever $uv$ is an edge in $F_\Omega(H)$, $f(u)f(v)$ is an edge in $F_\Omega(G)$. Now, that $uv$ is an edge in $F_\Omega(H)$ means that there is an $\omega \in \Omega$ and $f_\omega: \omega \to H$ such that $f(\omega) \ni u, v$.

        But consider what happens if we just compose $f_\omega$ and $f$ -- this will be a morphism from $\omega$ into $G$, and trivially we must have that $f(f_\omega(\omega)) \ni f(u), f(v)$, and so there must be an edge $f(u)f(v)$ in $F_\Omega(G)$, by definition of $F_\Omega$.
    \end{proof}
\end{lemma}

What is going on in the proof of Lemma \ref{lemma_representable_endofunctor_is_functor} is much clearer if we just think about it in terms of things being subgraphs of each other, forgetting the data of \emph{how} exactly they are subgraphs. Then the statement that $F_\Omega$ is a functor boils down to the statement that if $\omega$ is a subgraph of $H$ and $H$ is a subgraph of $G$, then certainly $\omega$ is a subgraph of $G$, and so $F_\Omega(G)$ must have all the edges $F_\Omega(H)$ has, since edges in $F_\Omega(G)$ represent the presence of a certain subgraph in $G$.

\begin{definition}
    The functor $\Pi: \G \to \Pset$ which sends a graph to its partition into connected components is called the connected components functor. Equivalently, we can think of it as taking the equivalence relation hull of the binary relation $E$ defining the edges.
\end{definition}

\begin{definition}\label{definition_representable_clustscheme}
    A clustering scheme $\Clust$ is \emph{representable} if we can write it as $F_\Omega \circ \Pi$ for some representable endofunctor $F_\Omega$. Notice that this means that all representable clustering schemes are functorial, being the composition of two functors.
\end{definition}

One somewhat surprising fact is that there are actually representable clustering schemes that are not finitely representable.

\begin{theorem} \label{theorem_exists_not_finitely_representable}
    There exists a representable endofunctor $F_\Omega$ which is not \emph{finitely} representable, that is, it is not equal to $F_\Gamma$ for any finite set of simple graphs $\Gamma$.
\end{theorem}

In order to give a proof of this, we first need a structural result about how these endofunctors behave.

\begin{remark}\label{remark_omegas_sent_to_cliques}
    For any $\omega \in \Omega$, it is trivial to see that $F_\Omega(\omega)$ must be a clique, since we can just take the identity morphism on $\omega$ to show that all edges must exist.
\end{remark}

In fact, which graphs are sent to cliques by $F_\Omega$ essentially determines what it does as a functor. We will see this even more precisely in the next section, but for now this lemma will suffice for our needs:

\begin{lemma} \label{lemma_representation_hull}
    For any set $\Omega$ of simple graphs and any simple graph $G = (V, E)$, it holds that $F_{\Omega \cup \{G\}} = F_\Omega$ if and only if $F_\Omega(G) = (V, V^2)$, that is, if $G$ is sent to a clique on its vertices by $F_\Omega$.

    \begin{proof}
        Suppose $F_{\Omega \cup \{G\}} = F_\Omega$. That $F_{\Omega \cup \{G\}}(G) = (V, V^2)$ is immediate by Remark \ref{remark_omegas_sent_to_cliques}, and so since $F_{\Omega \cup \{G\}} = F_\Omega$, we also have $F_\Omega(G) = (V, V^2)$, as desired.

        Now suppose $F_\Omega(G) = (V, V^2)$, and let $H$ be some arbitrary simple graph. We wish to show that $F_{\Omega \cup \{G\}}(H) = F_\Omega(H)$. 
        
        That edges of $F_\Omega(H)$ must also be edges of $F_{\Omega \cup \{G\}}(H)$ is obvious, so all we need to show is that edges of $F_{\Omega \cup \{G\}}(H)$ are also edges of $F_\Omega(H)$. So suppose $uv$ is an edge of $F_{\Omega \cup \{G\}}(H)$ -- that this is so must be because there is some $\omega \in \Omega \cup \{G\}$ and an $f: \omega \to H$ such that $f(\omega) \ni u, v$.

        If this $\omega$ is not $G$, then we are done. If it is $G$, we recall that since $F_\Omega(G)$ is a clique, there must be an edge $f^{-1}(u)f^{-1}(v)$ in it. Therefore there must exist some $\omega \in \Omega$ and some $g: \omega \to G$ such that $f(\omega) \ni f^{-1}(u), f^{-1}(v)$. But then the composition $g \circ f: \omega \to H$ will be a morphism from an $\omega \in \Omega$ into $H$ whose image contains $u$ and $v$, proving that $uv$ is an edge of $F_\Omega(H)$.
    \end{proof}
\end{lemma}

With this result in hand, we can now give a proof of the existence of a representable but not finitely representable endofunctor.

\begin{proof}[Proof of Theorem \ref{theorem_exists_not_finitely_representable}]
    Let, for each $i$, $\omega_i$ consist of a triangle with a tail of $i$ vertices, as shown in Figure \ref{figure_triangles_w_tails}, and let $\Omega = \left\{\omega_i \given i \in \N\right\}$. We claim that $F_\Omega$ is not equal to $F_\Gamma$ for any finite set of simple graphs $\Gamma$.

    \begin{figure}
        \centering
        \label{figure_triangles_w_tails}
        \includegraphics[width=0.6\textwidth]{graphics/triangles_w_tails.png}
        \caption{The family of graphs $\{\omega_i\}_{i=0}^3$.}
    \end{figure}

    To prove this, let us first define
    $$\bar{\Omega} = \left\{G \in \G \given F_\Omega(G) = (V_G, V_G^2)\right\}$$
    as the set of all things which $F_\Omega$ sends to cliques. By Lemma \ref{lemma_representation_hull}, $F_\Omega = F_{\bar{\Omega}}$, and $\bar{\Omega}$ is the greatest set with this property.

    A little bit of reflection will make it clear that $\bar{\Omega}$ is precisely the set of connected graphs which contain a triangle. Particularly, for any edge in such a graph, we can map the tail end of some $\omega_i$ onto that edge, the rest of the tail onto a path to the triangle in the graph, and the triangle of the $\omega_i$ onto the triangle of the graph. That $F_\Omega$ will send any triangle-free graph to a graph with no edges is clear, since there is no morphism from any triangle-containing graph such as $\omega_i$ into a triangle-free graph. Likewise, that it cannot send a disconnected graph to a clique is obvious.

    Now suppose for contradiction that $\Gamma$ is a finite set of graphs such that $F_\Gamma = F_{\bar{\Omega}}$. Lemma \ref{lemma_representation_hull} implies that we must have $\Gamma \subset \bar{\Omega}$, since if there were a $\gamma \in \Gamma \setminus \bar{\Omega}$ it'd be sent to a clique by $F_\Gamma$, and thus also by $F_{\bar{\Omega}}$, since we've assumed they are equal -- but we chose $\bar{\Omega}$ so that it already contains everything sent to a clique by $F_{\bar{\Omega}}$.

    So, let
    $$\delta = \max_{\gamma \in \Gamma} \max \left\{ d(u, v) \given u, v \in V_\gamma, v\text{ is in a triangle} \right\}.$$
    That is, $\delta$ is the furthest any vertex in any graph in $\Gamma$ is from a triangle. We claim that $F_\Gamma$ will not send $\omega_{\delta + 1}$ to a clique, proving it is not equal to $F_{\bar{\Omega}}$, giving our contradiction.

    That this is so is actually easy to see -- if $\omega_{\delta + 1}$ were sent to a clique, that must in particular mean there is an edge in $F_\Gamma(\omega_{\delta + 1})$ between the tail vertex and its neighbour. So there is some morphism from some $\gamma \in \Gamma$ that hits both vertices. However, such a morphism must also map the triangle in $\gamma$ onto the triangle in $\omega_{\delta + 1}$, since that is the only place the triangle can go. Then, however, it cannot also reach to the tail -- the tail is further away from the triangle than any vertex in any $\gamma$ is from the triangle. So no such morphism can exist, and we are done.
\end{proof}

\begin{remark}
    The construction in our proof of course works equally as well replacing the triangle by any connected graph that is not a line. So we have found a whole lot of examples of classes of graphs that give representable but not finitely representable endofunctors.

    The question of which natural classes of graphs are representable or finitely representable may be interesting. The connected graphs, for example, are of course represented by just a $K_2$. %Meanwhile, a not-too-difficult argument shows that the graphs of girth at least $k$ are representable but not finitely representable for any $k$. % <- I think this last bit is not actually true?
\end{remark}

\section{Proof of equivalence of representability and excisiveness}

We are able to exactly characterize the relationship between the three concepts of functoriality, representability, and excisiveness for clustering schemes.

\begin{theorem} \label{main_theorem}
    A representable clustering scheme is excisive. An excisive and functorial clustering scheme is representable. No other implications hold between these concepts.
\end{theorem}

We divide the proof of Theorem \ref{main_theorem} into two lemmas and a collection of examples.

\begin{lemma} \label{lemma_repr_implies_excisive}
    A representable clustering scheme is excisive.

    \begin{proof}
        Let $\Omega$ be some set of simple graphs, and $G$ be some simple graph. Assume the equivalence classes of $(F_\Omega \circ \Pi)(G)$ are $\{A_1, A_2, \ldots A_k\}$, and let $H = G|_{A_1}$ be the induced subgraph of $G$ on $A_1$. What we need to show is that $(F_\Omega \circ \Pi)(H) = (A_1, A_1^2)$, that is, that every vertex is equivalent in the clustering of $H$.
        
        It is obvious that this is equivalent to showing that $F_\Omega(H)$ is a connected graph. We will in fact show something stronger -- that $F_\Omega(H) = F_\Omega(G_{A_1}) = (F_\Omega(G))|_{A_1}$. Since $A_1$ is by assumption a connected component of $F_\Omega(G)$, this will show what we want.

        First, let $f: H \hookrightarrow G$ be the subgraph inclusion morphism of $H$ into $G$. By functoriality of $F_\Omega$, $f$ is also a morphism from $F_\Omega(H)$ into $F_\Omega(G)$, showing that $F_\Omega(H)$ is a subgraph of $F_\Omega(G)$, so every edge of $F_\Omega(H)$ is an edge of $F_\Omega(G)$

        Now, let $uv$ be an arbitrary edge of $F_\Omega(G)|_{A_1}$. We wish to show this is already an edge of $F_\Omega(H)$. That it is an edge of $F_\Omega(G)$ means there exists some $\omega \in \Omega$ and a morphism $f_\omega: \omega \to G$ such that $\im(f_\omega) \ni u, v$.

        We claim that in fact $\im(f_\omega) \subset A_1$, so that $f_\omega$ restricts to a morphism into $H$. If we can show this, this will show that there is an edge $uv$ also in $F_\Omega(H)$, and we will be done.

        So let $w$ be an arbitrary vertex in $\im(f_\omega)$. Now $f_\omega$ is also a morphism from something in $\Omega$ that hits both $w$ and $v$, so there is an edge $vw$ in $F_\Omega(G)$. But this of course means that $w$ and $v$ are in the same connected component -- and this connected component is precisely $A_1$. So $w \in A_1$, and we are done.
    \end{proof}
\end{lemma}

\begin{lemma} \label{lemma_exc_and_funct_implies_repr}
    An excisive and functorial clustering scheme is representable.

    \begin{proof}
        Let $\Clust$ be some excsive and functorial clustering scheme, and let
        $$\Omega = \left\{G \in \G \given \Clust(G) = (V_G, V_G^2)\right\},$$
        that is, $\Omega$ is the set of all graphs clustered by $\Clust$ into a single part. We will show that in fact $\Clust = F_\Omega$.

        So, let $G$ be some graph. We need to show two things:
        \begin{enumerate}
            \item Whenever $u$ and $v$ are clustered in the same part by $\Clust$, they are in the same connected component of $F_\Omega(G)$.
            \item Whenever $uv$ is an edge of $F_\Omega(G)$, $u$ and $v$ are clustered in the same part by $\Clust$. This of course implies that whenever $u$ and $v$ are in the same connected component, they are also clustered in the same part by $\Clust$, which is what we really need.
        \end{enumerate}
        
        We start with the first direction, letting $u$ and $v$ be two vertices that are sent to the same part by $\Clust$ -- call this part $A$, and let $H = G|_A$. By excisiveness of $\Clust$, we have that $\Clust$ sends $H$ to a single part, so $H \in \Omega$. Therefore, the inclusion morphism $f: H \hookrightarrow G$ is a morphism from something in $\Omega$ that hits both $u$ and $v$, showing there is an edge $uv$ in $F_\Omega(G)$, as desired.

        In the second direction, assume that $uv$ is an edge of $F_\Omega(G)$. Thus, there is some $\omega \in \Omega$ and $f_\omega: \omega \to G$ such that $\im(f_\omega) \ni u, v$. By functoriality of $\Clust$, $f$ will also be a morphism from $\Clust(\omega)$ into $\Clust(G)$ -- which by how we defined morphisms in the category of partitioned sets means that any two vertices equivalent in $\Clust(\omega)$ must also be equivalent in $\Clust(G)$. However, we defined $\Omega$ as precisely the set of things such that $\Clust(\omega)$ has only a single part -- so everything is equivalent in $\Clust(\omega)$ and in particular $u \sim_{\Clust(\Omega)} v$, and so they are also equivalent in $\Clust(G)$, as desired.
    \end{proof}
\end{lemma}

Finally, let us think about what we need to show to demonstrate that there are no other implications between these concepts. An implication between these concepts is logically the same thing as a proof that some combination of them is impossible -- so what we will do is just to draw a two-by-two-by-two table of all combinations, and fill in which cells our theorems already rule out, and give examples of clustering schemes for every other cell.

\include{2by2by2_table_paper}

\begin{example}\label{ex_allthreeprops}
    The connected components functor $\Pi$ is representable and excisive -- we can take its representation to be $\Omega = \{K_2\}$.
\end{example}
    
\begin{example}\label{ex_excnotfunctnotrepr}
    For a scheme that is excisive but not functorial (and thus not representable), consider the scheme that partitions all graphs into a single part except $K_2$, which it partitions into two parts.
\end{example}
    
\begin{example}\label{ex_functnotexcnotrepr}
    For a scheme which is functorial but neither excisive nor representable, cluster all connected components on more than two vertices as well as all isolated vertices as their own parts. 
    
    If there is exactly one component on two vertices, i.e. an isolated edge, cluster it as two parts, otherwise cluster all isolated edges as single parts.
\end{example}
    
\begin{example}\label{ex_noprops}
    Finally, for a scheme which has none of the properties, cluster all graphs as a single part except for $K_2$, which we cluster as two parts, and the disjoint union of two copies of $K_2$, which we cluster as two parts -- that is, each of the copies is its own part.
\end{example}
